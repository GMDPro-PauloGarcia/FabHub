Getting Started

FabHub is GMD's internal operations platform connecting all departments — from first client contact to final payment collection.

How to Access

  • Open any browser: fab-hub.vercel.app
  • Works on desktop, tablet, and mobile
  • No app download needed
  • Enter your username and password (Chapter 2)

Grouped Navigation

Each role's sidebar is organized into department sections so you always know where to look. Groups collapse into icons when you click the ← toggle.

RoleNav Groups
ManagerOverview (Dashboard, Calendar) · Sales · Finance · Operations · Design · Procurement · QS/Cost · Admin (Accounts, Bot Settings)
SalesPipeline (Sales Pipeline, Clients) · Projects · Deliverables (Design Requests, Checklist)
FinanceOverview (Cash Position) · Financials (Billing, Accounting, Collections) · Projects
ProcurementOverview · Orders (POs, Material Requests, Budget Requests) · Materials (Swatchboard) · Projects
QSOverview · Projects (Projects, Cost Analysis)
OperationsOverview (Projects, Calendar) · On-Site (Project Cards, Job Orders, Checklist) · Requests
DesignOverview · Design Work (Design Requests, Project Cards, Checklist, Swatchboard)
ProjectMoverOverview · Updates (PM Updates, Scope Changes) · Work (Job Orders, Checklist)
WarehouseOverview · Stock (Deliveries, Inventory, Stock Movements)
All data is stored in Supabase (cloud database). Clearing your browser cache will NOT delete your data — everything is safe and syncs automatically when you log back in.

Procurement

Manager Procurement Operations

Material Requests (Operations submits)

Go to Material Requests → click + Request Materials → fill in item, qty, project, urgency, purpose → Submit. Procurement reviews and either converts to PO or rejects.

Purchase Orders (Procurement manages)

Go to Purchase Orders → + New Purchase Request → fill in item, supplier, qty, estimated cost, budget category → Issue PO when placed → Log delivery when received.

Budget Requests (Operations submits)

For cash needs on site (installation, mobilization, permits): Budget Requests tab → + Request Budget → select purpose, amount, urgency → Submit. Finance approves and releases.

🤖 Telegram triggers: New Material Request → Procurement channel. New Budget Request → Management channel. PO Approved → Procurement channel.

Create 6 Telegram group chatsOne per department: General, Operations, Design, Procurement, Sales, Management

Add the bot to each group as adminOpen each group → Add Member → search your bot's username → Add

Get each group's Chat IDSend a message in the group, then visit: api.telegram.org/bot[TOKEN]/getUpdates — look for the negative number next to "chat":{"id":

Open FabHub → 🤖 Bot Settings (Admin group in Manager sidebar)Paste the Bot Token and all 6 Chat IDs → Save. Use Test buttons to verify each channel.
