What's New in v1.4 LATEST

All Roles

Version 1.4 (June 1, 2026) introduces QS pricing ownership, role-based value visibility, pipeline improvements, and several data quality fixes. Below is the complete change log.

💰 QS Pricing — QS Now Sets the Client Submission Price

QS is now the pricing gatekeeper. After completing a cost study, QS enters the final proposal amount via a ₱ button in the Sales Pipeline. Sales then quotes that price to the client. This ensures every submission has been validated against a cost study before going out.

  • Purple ₱ button on each active deal (QS pipeline view) — opens "Set Client Submission Price" modal
  • Enter contract amount + optional costing note
  • Saves to deal history; Sales team receives a Telegram notification automatically
  • Deals with a price show ₱✏ (update) instead of ₱ (set)

👁 Role-Based Value Visibility

Production teams (Operations, Design, ProjectMover) no longer see the client contract price. Instead, they see the QS production budget total (Materials + Labor + Overhead + Subcon) shown in purple. If QS has not set a budget yet, they see "Budget Pending".

RolePipeline value shownProjectCards value shown
Manager, Sales, Finance, QSContract value (₱)Contract value (₱)
Operations, Design, ProjectMoverQS Budget 📊QS Budget 📊

🏆 Sales Can Award Directly

Sales team members now see a green 🏆 Award button and can complete the full award flow (Job Order + scope + PM assignment) without requiring Manager approval. This removes the bottleneck when Paulo is on mobile or unavailable.

👤 AE Badges & Filter

  • AE badge appears on every deal row showing the Account Executive's first name
  • AE filter chips (purple) above the pipeline let Manager filter by salesperson
  • On Sales home cards, a badge shows when viewing a deal owned by a different team member (e.g. 👤 Gail)

📋 Sales → Ops Handoff Improvements

  • Sales Repo link (📁 Sales Repo button) now visible in the OpsView project header and on every ProjectCard — PMs can open the folder directly
  • Project Brief & Handoff panel added to OpsView Progress tab — shows DRF data (size, designer, deadline, accessories, ref links), JO scope/instructions/location, and links to Approved Files
  • Design Brief panel auto-appears when DRF or JO scope data exists for a project

🏢 Client Directory Improvements

  • "City" column replaced with Awarded Deals — shows number of projects won and total contract value per client
  • Contact column now reads from the saved Client Profile (contact person + phone)
  • Add Client form now includes full profile fields in one step: contact person, email, phone, billing address, TIN, payment terms, notes

🔔 Telegram Notification Fix

Bot settings are now read from Supabase across all user devices, not just the device where settings were configured. Sales users on their own devices now correctly receive and send notifications for new deals and project awards.

📊 Pipeline Visibility for More Roles

  • Operations now has "Sales Pipeline" in their sidebar — useful for seeing what's coming before it lands in their lap
  • Design now has "Sales Pipeline" in their sidebar — useful for capacity planning
  • Pipeline actions (Edit, Did Not Win, move-back) are restricted to Manager and Sales only; other roles can only view and request awards

🐛 Data Quality Fixes

  • Active deal counts now correctly exclude "Did Not Win" and "Cancelled" everywhere (pipeline header, AE filter chip, Manager KPI)
  • Follow-up "OVERDUE" warnings no longer appear for won or closed deals
  • Checklist project dropdown no longer includes already-won deals in the "pre-award" list
  • E-4 escalation now correctly routes to the DRF view (was routing to a non-existent "drfs" page)

How the Numbers Are Calculated

MetricSource
Revenue BilledBilling milestones grouped by invoice date
CollectedBilling payments grouped by payment date received
ExpensesLogged expenses grouped by expense month
Gross ProfitRevenue Billed minus Expenses
GP%Gross Profit ÷ Revenue Billed × 100
Expenses must be logged by the accounting team using the + Log Expense button in the Finance page. Expenses that are not logged will not appear in the P&L — the report is only as accurate as the expense entries.

🚨 Process Compliance & Escalations NEW

Manager

The Process Compliance panel appears on the Manager Dashboard. It automatically scans all active projects and surfaces escalation alerts when process rules are breached — so nothing falls through the cracks.

Escalation Types

CodeIssuePriority
E-1Overdue billing milestone — due date has passed and milestone is not fully paidHIGH
E-2Unresolved scope change — addendum still in "Discovered" status, not yet approved or rejectedMEDIUM
E-3Punchlist SLA breached — project has been in "11 · Punchlist" stage for more than 5 business daysHIGH
E-4DRF deadline within 7 days — design request approaching its due dateMEDIUM
E-5PO delivery overdue — purchase order delivery date has passed without confirmationHIGH
E-6Budget request pending more than 3 days without approval or rejectionLOW
E-7Won project (Stage 6 or higher) with no billing milestones set — Finance has not been set up yetHIGH

COC → Finance Link

When the PM issues a Certificate of Completion (COC) in the Ops Close-Out tab of a project, a banner automatically appears in the Billing view for that project. This notifies Finance that the project is complete and final payment can be collected.

Punchlist SLA

The maximum time allowed in the 11 · Punchlist stage is 5 business days. The timer starts automatically the moment a project's stage is moved to Punchlist. If the stage has not advanced after 5 business days, an E-3 escalation is raised on the Manager Dashboard.

Warranty Tracking

After close-out, the PM can activate a warranty period directly from the Close-Out tab in Ops. Three warranty durations are available: 30 days, 60 days, or 90 days. The warranty clock starts from the COC date. Active warranties appear on the Manager Dashboard so no warranty obligation is forgotten.
